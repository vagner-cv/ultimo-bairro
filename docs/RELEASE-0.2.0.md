Primeira versão com o kit gratuito **Zombie Apocalypse Top-Down Pixel Art**, da CraftPix, integrado ao cenário e aos personagens.

Para jogar no PC:

- **Windows:** baixe `UltimoBairro-0.2.0-Windows.zip`, extraia todos os arquivos e abra `UltimoBairro.exe`.
- **Linux:** baixe `UltimoBairro-0.2.0-Linux.zip`, extraia e execute `UltimoBairro.x86_64`.

Não é necessário instalar Godot ou Python para usar esses executáveis. Esta entrega ainda não tem uma versão para navegador.

Controles: **WASD** ou setas para andar, **mouse** para mirar, **botão esquerdo** para atirar, **E** para portas e conversa, **Esc** para pausa e **roda do mouse** para zoom.

Inclui um bairro com cinco construções, uma NPC, 18 infectados, pistola infinita, dano, morte e reinício. Sem coleta, inventário ou salvamento nesta etapa. Os personagens usam as animações laterais prontas do kit.

Validação: **32/32 testes de gameplay**, preparação e importação de um checkout limpo e teste do executável Linux com teclado/mouse. O pacote Windows foi exportado em Linux e ainda precisa de validação em uma máquina Windows.

O ZIP de código contém os scripts de preparação dos assets, sem redistribuir o pacote gráfico. Os executáveis incluem a arte como parte do jogo, com o aviso de uso da CraftPix.
